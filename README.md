## 🦫 Overview: What is Capybara Bot?

### The Capybara Philosophy
Capybaras are world-renowned as the most peaceful, chill, and friendly animals on Earth—naturally relaxing alongside ducks, monkeys, turtles, and humans alike. 

The **Capybara Discord Bot** brings that exact spirit of calm joy directly to your Discord community. Built from the ground up using modern **Discord.js v14**, it delivers instant, high-resolution capybara photography, interactive button controls, a gamified collection tracker (**Capydex**), server leaderboards, and live web photos fetched dynamically from across the internet.

### System Architecture Overview

The bot operates through an asynchronous, event-driven architecture connecting Discord's Gateway with local assets, external APIs, and persistent storage:

## ✨ Features in Depth

### 📸 Dual Image Delivery Engine (Local & Live Web API)
* **Local Curated Gallery**: 25 hand-selected, verified high-resolution capybara images packaged directly inside the repository (`images/`). These images load with zero latency and zero reliance on external network availability.
* **Live Web API Integration**: Connects dynamically to `api.capy.lol`, giving users access to an expanding pool of over 820+ live web photos.
* **Resilient Offline Fallback**: If the external web API experiences downtime or network latency, the bot automatically catches the error and attaches [images/hello.jpg](./images/hello.jpg) with an informative status card. The bot process will **never crash** due to remote API outages.

### 🎨 Dynamic & Expressive Embeds
* **Randomized Border Accents**: Every capybara response generates a unique hex color border (from `0x000000` to `0xFFFFFF`), making every photo embed visually distinctive.
* **Contextual Captions**: Each local image is paired with a hand-crafted caption matching the mood (e.g. *chilling, gaming, reading, swimming, family, babies*).
* **Dual-Line Footer Attribution**: Embed footers display user attribution, request timestamps, and live collection progress:
  ```text
  Image 05/25 • Requested by User#1234 at 10:45 AM
  * Collection: Capys: 14/25 • Web: 85/821
  ```
* **Auto Reactions**: The bot automatically adds custom or unicode emoji reactions upon message delivery.

### 📖 Capydex Collection Tracker & Dynamic API Sync
* **Persistent Progress Tracking**: Tracks every individual capybara photo unlocked by each user across both the local curated collection and live web photos.
* **Option B 100-Block Visual Progress Bars**: Renders clean, high-precision visual progress bars inside ephemeral cards:
  ```text
  Local Curated Capys:
  [■■■■■■■■■■■■■■■■■■■■□□□□□] 80.0% (20/25)
  ```
* **Dynamic Binary Search Pool Probing**: On startup and daily intervals, the bot automatically probes `api.capy.lol` via binary search to discover new remote photos added by the upstream API without requiring code updates.
* **Milestone Guidance**: Tells users exactly which photo numbers they are missing to help them complete their collection.

### 🏆 Capydex Leaderboard & Gaming Tiebreaker Hierarchy
* **Ephemeral Server Leaderboard**: Click the 🏆 button to inspect the top 5 collectors in your server without cluttering the public chat channel.
* **Medal Recognition**: Top 3 ranks feature gold, silver, and bronze medals (`🥇`, `🥈`, `🥉`).
* **Personalized Standing Row**: If you are ranked outside the top 5, a dynamic divider (`•••`) appears, followed by your exact rank and unlock count (`👉 #14 • @User — 18 Capys`).
* **Multi-Tier Tiebreaker Hierarchy**: Resolves rank ties using a rigorous 4-tier gaming hierarchy:
  1. Total overall unlocked capybaras.
  2. Total local curated capybaras unlocked.
  3. Earliest timestamp of 100% collection completion.
  4. Earliest timestamp of initial player activity.
* **Rare Bonus Encounters**: Rare bonus photos (`bonus1.jpg`, `bonus2.jpg`, `bonus3.jpg`) captured by [@mikroskato62](https://github.com/mikroskato62) feature a weighted ~2% drop rate each (~6% combined), providing an exciting rare discovery experience.

### 🔄 Interactive In-Place Navigation & Author-Only Security
* **Seamless Message Cycling**: Click 👍 **Next** to cycle to another random photo in-place using Discord message edits, avoiding channel spam.
* **Interactive Buttons**:
  * 👍 **Next (`capybara_next` / `capyweb_next`)**: Cycles to another random photo.
  * 🦫 **React (`capybara_react`)**: Adds a fun random animal/nature emoji reaction.
  * 📖 **Capydex (`capydex_view`)**: Opens your personal collection tracker.
  * 🏆 **Leaderboard (`capyleaderboard_view`)**: Opens the server collector leaderboard.
  * 👎 **Leave (`capybara_leave`)**: Dismisses the photo with an animated farewell.
* **Author-Only Protection**: The user ID of the command author is cryptographically encoded into button component metadata. If another user attempts to click **Next** or **Leave**, Discord blocks them with an ephemeral notification: *"Only the user who ran the command can control this interaction."*

### 🛡️ Anti-Spam Rate Limiting & Cooldown Protection
* Features an internal **1-second per-user cooldown** across all slash commands and button interactions.
* Protects Discord servers from chat floods and ensures your bot token remains safely within Discord API rate limits (`HTTP 429 Too Many Requests`).

## 🚀 Quick Start Guide (Local Development)

Follow these steps to run the bot on your local computer for testing and development:

### Step 1: Prerequisites
Ensure you have the following installed on your machine:
* **[Node.js](https://nodejs.org/)** (v18.0.0 or higher LTS recommended). Check by typing `node -v` in your terminal.
* **[Git](https://git-scm.com/)** command-line tools. Check by typing `git --version`.
* A **Discord account** and a personal Discord server where you can invite test bots.

---

### Step 2: Clone Repository & Install Dependencies

Open your command prompt or terminal and clone the repository:

```bash
# Clone the repository to your computer
git clone https://github.com/mikroskato62/capy-discord-bot.git

# Enter the project directory
cd capy-discord-bot

# Install dependencies (discord.js, dotenv, unicode-emoji-json)
npm install
```

---

### Step 3: Creating Your Bot & Getting Credentials from Discord

1. Navigate to the **[Discord Developer Portal](https://discord.com/developers/applications)** and sign in.
2. Click **New Application** in the top right corner.
3. Enter `Capybara Dev` (or any custom name) and click **Create**.
4. **Copy Client ID**:
   * On the **General Information** page, locate **Application ID**.
   * Click **Copy** and store this as your `CLIENT_ID`.
5. **Generate Bot Token**:
   * In the left menu, click **Bot**.
   * Under the **Token** header, click **Reset Token** and confirm.
   * Click **Copy** and store this as your secret `TOKEN`.
6. **Invite the Bot to Your Server**:
   * In the left menu, click **OAuth2** $\rightarrow$ **URL Generator**.
   * Under **Scopes**, select: `bot` and `applications.commands`.
   * Under **Bot Permissions**, select:
     * Send Messages, Embed Links, Attach Files, Add Reactions, Use External Emojis, Read Message History, View Channels.
    * Copy the **Generated URL** at the bottom, open it in your browser, and authorize the bot to your private test server.

> [!TIP]
> **Zero Privileged Gateway Intents Needed**:  
> Capybara Bot only requires standard guild gateway connectivity (`GatewayIntentBits.Guilds`). You **do NOT need to enable any Privileged Gateway Intents** (such as *Message Content Intent*, *Server Members Intent*, or *Presence Intent*) in the Discord Developer Portal. This makes self-hosting completely frictionless, secure, and verification-free!

---

### Step 4: Configure Environment Variables (`.env`)

Create a `.env` file in the root directory of your project (referencing [.env.example](./.env.example)):

```env
TOKEN=your_discord_bot_token_here
CLIENT_ID=your_discord_client_id_here
```

*(Optional custom emoji configuration)*:
```env
CUSTOM_EMOJI_ID=your_custom_bot_emoji_id_here
```

> [!CAUTION]
> Never commit your `.env` file to GitHub or share your `TOKEN` with anyone! The `.env` file is already protected by [.gitignore](./.gitignore).

---

### Step 5: Deploy Slash Commands

Publish the slash command definitions to Discord's servers:

```bash
npm run deploy
```

You should see:
```text
[*] Started refreshing 3 application (/) commands...
[+] Successfully registered 3 global application (/) commands! 🎉
[+] Commands are now live across all servers where the bot is invited.
```

---

### Step 6: Launch the Bot

Start the application:

```bash
npm start
```

When successful, your console will output:
```text
[!] Capybara: Hello World!
[!] Success :)
[!] Logged in on discord as Capybara Dev#1234 ...
[!] Dynamic Web Capybara pool verified: 821 total images.
```

Open Discord, type `/capybaras` in your test server, and enjoy your capybaras! 🎉

> [!IMPORTANT]
> **The Golden Rule of Discord Bot Testing**: Never run your local code using the same Bot Token that is currently active on your 24/7 cloud host! Doing so causes Gateway event conflicts and "Interaction already replied to" errors. Always use a separate `Capybara Dev` bot for local testing.

## 🔐 Configuration & Environment Variables

| Variable | Type | Mandatory? | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| **`TOKEN`** | `string` | **Yes** | *None* | Secret Discord Bot Authentication Token used for Gateway login and REST authorization. |
| **`CLIENT_ID`** | `string` | **Yes** | *None* | Discord Application (Client) ID used for global slash command deployment via REST. |
| **`CUSTOM_EMOJI_ID`** | `string` | No | `null` | Optional snowflake ID of a custom server emoji. Gracefully falls back to unicode `🦫` if omitted or invalid. |
| **`GUILD_ID`** | `string` | No | `null` | Optional legacy server ID. When present during command deployment, legacy guild-scoped commands are automatically cleared to prevent duplicate commands. |
