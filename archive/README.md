# 📂 Capybara Discord Bot — `archive/` Source Code Workspace

This directory contains the all-in-one merged version of the bot logic preserved in a single file: [`code.js`](./code.js).

---

## 💡 Purpose & Usage

- **Single-File AI Chatbots**: Easily copy/paste or upload `code.js` to any web-based AI chatbot (ChatGPT, Gemoni, Claude, etc.) when you want help analyzing or modifying the entire bot logic in one place.
- **Autonomous AI Agents**: Direct multi-file AI agents (like Antigravity / Claude Code / Codex) to the modular [`src/`](../src/) directory for easier, structured updates.
- **Standalone Execution**: Can be run directly with: `node archive/code.js`
